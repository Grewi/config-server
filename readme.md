# D-Electronic

## Создание контейнера сайта 
1. В директории `/sites` создать директорию для конфигурации сайта 
2. Имя директории должно совпадать с именем файла конфигурации nginx (например `newsite.ru`)
3. За основу можно взять пример конфигурации **samle.site** 
4. В `docker-composer.yml`  сайта вместо `site-name` указать новое имя контейнера
5. Вместо `../../../www/site_dir` указать путь к сайту (например `../../../www/newsite.ru`)
6. Создать файл `.env` и указать версию php или указать свой путь к `Dockerfile` в `docker-composer.yml`
7. Если необходимо редактировать конфигурацию `apach` в файле `config/000-default.conf` 

## Создание конфигурации 
1. Сгенерировать ssl сертификаты для нового домена в директории `certs` например утилитой `mkcert`
2. Создать конфигкрацию в директории `conf.d` За основу можно взять образец **sample_config**.
3. Желательно что бы наименование конфигурации `/conf.d/name.conf` совпадало с именем `/sites/name`
4. В возданном файле `host.name` заменить на необходимый хост (например `newsite.ru`)
5. `container_name` заменить на имя контейнера 
6. Указать сгенерированные сертификаты .

## Добавление сайта
1. В файле **.stacks.list** прописать путь к директории, один путь на каждой строке. 
2. Если такого файла нет, создать в корне проекта
3. Допускается комментирование строки символом `#` такая конфигурация загружена не будет

## Подключение базе данных 
1. Если сайту необходимо подключение к базе данных можно использовать уже существующую конфигурацию 
2. Если требуется отдельная конфигурация, тогда она должна быть прописана в `docker-composer.yml` самого сайта 
3. Для подключения к базе использовать данные указанные в `/db/.env`
4. Зайти по root создать базу данных и пользователя для неё 
5. Выдать права новому пользователю для работы с новой базой 
6. Для подключения указывать имя контейнера `db` в host-name, наименование созданной базы данных, имя и пароль созданного пользователя 

## Запуск
`./start.sh`

## Остановка
`./stop.sh`
