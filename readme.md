# D-Electronic

## Добавление сайта
1. Сгенерировать ssl сертификаты для нового домена в директории certs
2. Создать конфигкрацию в директории conf.d За основу можно взять образец **sample_config**. Необходимо указать сгенерированные сертификаты и указать точку входа для приложения.
3. Создать конфигурацию сайта в директории, можно использовать пример **samle.site** 
4. В файле **.stacks.list** прописать путь к директории, один путь на каждой строке. Если такого файла нет, создать в корне проекта
